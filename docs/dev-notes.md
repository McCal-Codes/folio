# Folio Dev notes: steps to try in this build

Optional. Each "- " line becomes a checkbox on Folio Dev's "New build" page (Settings > General > Tips > This build). The build number is the branch's commit count, so a higher number is always the newer build.

- Fold position: on a foldable, swipe to page 3 on the cover, unfold and swipe to page 1, then fold. The cover should be back on page 3, and unfolding again goes back to page 1. A screen you have not used yet keeps the page you were on.
- Fold with the App Library: open the App Library, open a category or scroll down, then fold or unfold. The library, the open category and the scroll should stay where they were.
- Photos widget: add Photos from the widget picker, pick a few photos, and watch it advance. Tap it for Show the date, Shuffle and the speed.
- Photos menu: hold the widget. Edit Widget opens its options, and More has Remove This Photo, which takes the showing photo out.
- Widget menu: hold any widget. A small popover opens beside it (below, above, or over a tall widget), the widget stays lit and the rest of Home dims. It lists Edit Widget, Size, Replace Widget, Make a Stack, Edit Home Screen and More, with Remove Widget in red at the bottom.
- Widget size: in the widget menu, open Size. The widget's current size has a checkmark, a size it cannot take is dimmed, and choosing one resizes it and closes the menu. Back (the arrow or the back button) returns to the list.
- Widget menu, More: Custom Size has width and height steppers and Apply Size, Move to Page checks the page the widget is on, and a stack adds Edit Stack. Every action the old sheet had should still be reachable.
- Edit bar: hold Home, unfolded and on the cover screen. Add, Edit, Undo, Redo and Done should sit at the top with nothing overlapping, and the dock handle under the dock stays clear.
- Blue dot: Folio now reads the Wi-Fi name once per network. Watch the top right: the location dot should stay off, and the name should still show on the status rail and in Control Center. Join another Wi-Fi and check the new name appears.
- Undo and redo: move an icon, then tap Undo in the top bar, then Redo.
- Control Center edit: open Control Center, tap Edit, hold a tile to move it, drag a corner to resize it.
- Add a Control: tap Add in Control Center's edit mode. Search, and check the sections.
- Reduce Motion: turn it on in Settings. The Photos widget should switch photos with no fade and show no play button, and the widget menu should fade in and out without growing.
- Large text: set the phone's font size to the largest. Check the widget menu, its Size and More levels, and Photos options for clipping: labels should wrap and the menu should scroll, with Remove Widget still in view.
- Tips: open Settings > General > Tips. Each new feature should have a row, newest version first.
