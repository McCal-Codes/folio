# Folio 0.6.7.1: searching works again

One fix on top of 0.6.7, the first release to use the hotfix digit (ADR 0007, REL-12).

## What it fixes

#166: typing in the App Library's search field showed nothing on 0.6.7. #147 let the search field grow for large
text, and its clear button then filled all the height it was offered, so the field took the whole panel and the
results got none. The same field is used by Settings search, Choose Home Apps, the Market's sources and icon stacks,
so all five were affected. Fixed in #167; `SearchFieldHeightTest` fails without the fix.

## Version

`folioVersion = "0.6.7.1"`, `versionCode` **6071** (0.6.7 was 6070), so it installs over 0.6.7 and every 0.6.7
beta. `SoftwareUpdate.isNewer` orders 0.6.7 < 0.6.7.1. Settings › Roadmap reads 0.6.7.1 as part of the 0.6.7
section (#167), so `roadmap.json` doesn't change.

## No beta first

REL-20 asks for a beta before anything that changes how Folio updates, installs or checks a supporter code. This
touches none of that: one layout fix and the Roadmap's version comparison. REL-15 is met because no 0.6.7.1 beta
exists for the stable to carry less than.

5. Reply on #166 that 0.6.7.1 fixes it.
