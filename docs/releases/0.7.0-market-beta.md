# 0.7.0 Market beta: plan and acceptance checklist

Not a version note. This is the plan for the beta that carries only the Market, so it is finished before anything else goes on top of it. It becomes `0.7.0-beta.4` when beta 3 (dock, Beta access, Older versions) is out. Owner decisions (11 Nov 2026): all built-in tweaks move to packages, the beta is Market-only, and it must look right.

## What "all tweaks move to packages" means

The package format never adds behavior Folio does not already have (ADR 0004, `docs/sdk/format-v1.md`), so the code for each tweak stays in the app. What moves is the unit people install, update and remove: each built-in tweak becomes a package in the community repository, with its own listing, version, options and defaults. A copy of each is bundled in the app, so a tweak works offline and when a source is down.

The eight built-in tweaks (`FeatureScopes.kt`, `TweakFeatures`): Cabinet, Harborline, Roll Call, Palette, Afterglow, Flipbook, Duet, StandBy 2.

## Work

1. **Packages.** One `tweakBundle` per tweak, built and checked with `tools/folio-pkg.py`, signed with the packages key, published to the community repository. Duet's options are the only ones today.
2. **Bundled copies and migration.** The bundled source carries all eight. Anyone with a tweak on, and every default-on tweak (Duet, StandBy 2), is migrated with their settings kept (`PackageInstaller.updateKeepingSettings`). Removing a package turns the tweak off. The `TweakFeatures` rows stay so removal keeps working.
3. **Updates.** Package updates go through the normal Market update path, with undo. A community source that claims a built-in id is still refused as an impostor unless it carries the packages key.
4. **Market fixes from the audit.** Offer and install floor agree (compare `versionCode` in `MarketAppUpdate.kt`, not only names); search on Browse; a TalkBack pass on Get, Update and Sources; the depiction markdown limits MKT-9 to MKT-12 enforced in the app and `folio-pkg` from one shared list; confirm the "verified" label comes only from the manifest and signature (MKT-13).
5. **Looks.** A design pass on Browse, package pages, Updates and Sources: light and dark, cover and inner screens, empty, loading and error states.

## Acceptance checklist (every box before the beta goes out)

- [ ] All eight tweaks install, update, and remove from the Market, and each works after each step.
- [ ] A phone with a tweak already on keeps it on, with its settings, after the update.
- [ ] Duet and StandBy 2 are still on for phones that had them on, and off for those that turned them off.
- [ ] With no network, every bundled tweak still works and the Market says why it cannot refresh.
- [ ] A source that is down, stale, or lists a bad package never changes what is installed (MKT rules; existing tests plus new ones for the tweak packages).
- [ ] An update that is offered always installs (versionCode and name agree).
- [ ] Search finds packages and sources, and every Market screen has TalkBack labels and a sensible focus order.
- [ ] Screens checked in light and dark, cover and inner, with large text, at the smallest and largest window.
- [ ] `folio-pkg` and the app reject the same depiction markdown.
- [ ] Layout Backup, restore and Older versions round trip with the tweaks installed.
- [ ] Release notes say what to try, most likely broken first (REL-21); SHA-256, VirusTotal and PERMISSIONS.md are ready (REL-22 to 24).
- [ ] At least a day with supporters before anything else lands (REL-20), and about a week before beta 5.

## Not in this beta

Rows beyond 7, the left and right dock edge, and anything outside the Market go to beta 5 so this beta can be judged on the Market alone.
