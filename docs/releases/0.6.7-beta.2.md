# Folio 0.6.7-beta.2 for supporters

The first beta that reaches supporters through the private channel, and the last one handed out by hand. It carries
the two-pane layout (#72) and Folio Beta in the Market, which is how every later beta arrives.

Branch `folio-beta-source`, on top of `two-panes`. Version `0.6.7-beta.2`, versionCode 607, so it installs over
0.6.6 (606) and 0.6.7 installs over it.

## Why this one goes by hand

0.6.6 can't see a private beta: its `BETA_BROKER` is empty, so Beta Updates only reads public pre-releases from
`McCal-Codes/folio`. This build is the first with the broker's address in it. Supporters install it once from the
Ko-fi post; after that, Market › Sources › Folio Beta offers each new beta by itself.

## 1. Deploy the supporter worker (done 22 Sep 2026)

Live at `https://folio-supporter-codes.mccal.workers.dev` on the **McCal** Cloudflare account, D1 `folio-codes`
(`a878ea66-ca8b-426a-8ed9-ecdcf0c5e9ed`) with the 100 pool codes, `GITHUB_TOKEN` and `TICKET_SECRET` set. What
follows is how it was done, for next time.

Everything runs in `tools/kofi-worker`. Wrangler's saved login on the Mac had expired on 22 Sep, so start there.

```bash
cd ~/dev/duo-fold-launcher/tools/kofi-worker
wrangler login
wrangler d1 create folio-codes
```

Paste the `database_id` it prints into `wrangler.toml` (it isn't a secret). Then set, in the same file:

```toml
BETA_REPO = "McCal-Codes/folio-beta"
SUPPORTER_KEYS = "MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAEM4vVq0D/ZzqkVWlyQYMTFN3TTbdqRgKdt2a30T88NkeQhDEWnujFjfyXyKtPIVBKMSiRVXeY/OcC0+TaB6eypg=="
```

That key is `BetaKeys.SUPPORTER`, the public half the app already carries.

```bash
wrangler d1 execute folio-codes --remote --file=schema.sql
wrangler d1 execute folio-codes --remote --file=pool.sql      # the 100 pool codes (gitignored)
openssl rand -base64 48 | wrangler secret put TICKET_SECRET
wrangler secret put GITHUB_TOKEN
wrangler deploy
```

`GITHUB_TOKEN` is a fine-grained token with **Contents: read on McCal-Codes/folio-beta and nothing else**
(github.com › Settings › Developer settings › Fine-grained tokens). `KOFI_TOKEN` and `RESEND_KEY` are only for the
Ko-fi webhook and can wait.

`wrangler deploy` prints the address, `https://folio-supporter-codes.mccal.workers.dev`. Check it:

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://folio-supporter-codes.mccal.workers.dev/beta/releases
```

`400` is right (no code sent). Send Claude the address.

## 2. Put the address in the app (done, 26c6dd7)

`SoftwareUpdate.BETA_BROKER` gets the address, one commit on `folio-beta-source`, unit tests again.

## 3. Sign it (done: certificate `bad8e099…d8441`, APK SHA-256 `8914a091…4bfd`)

The **original** keystore, the one 0.6.6 was signed with (`~/folio-release.jks`, alias `folio`, certificate SHA-256
`bad8e099…d8441`). Not `~/folio-release-2026.jks`: that was 0.6.5's wrong signer, and a beta signed with it installs
on nothing.

```bash
cd <the folio-beta-source worktree>
FOLIO_RELEASE_STORE_FILE=~/folio-release.jks FOLIO_RELEASE_KEY_ALIAS=folio \
  FOLIO_RELEASE_STORE_PASSWORD=… FOLIO_RELEASE_KEY_PASSWORD=… ./scripts/release-signed.sh
```

Output: `dist/Folio-0.6.7-beta.2/` with the APK, `SHA256SUMS.txt` and `signing-certificate.txt`.

## 4. Publish (done: `v0.6.7-beta.2` on folio-beta; listing, download and checksum checked through the worker)

- Check the certificate is `bad8e099…d8441`.
- `gh release create v0.6.7-beta.2 -R McCal-Codes/folio-beta --prerelease` with `Folio-0.6.7-beta.2.apk`,
  `SHA256SUMS.txt` and the notes below. The app needs an asset ending `.apk` and one named exactly `SHA256SUMS.txt`.
- Ask the worker for the list with a real code and confirm the release shows up with rewritten download links.

The supporters-only Ko-fi post, with the APK attached or linked, its SHA-256, and the notes below. Installing it

## Release notes (what Folio shows in the update card; McCal's words to edit)

```markdown
**Folio 0.6.7 beta 2, for supporters**

- **Folio Beta in the Market:** Sources now has Folio Beta, with what you're on and the newest beta. From here on,
  new betas show up there with an Update button, so there's nothing to download by hand.
- **Panes fit the screen:** on the Fold's inner screen the Market and Settings use two panes, like an iPad. A
  package, a source or a nested setting opens over the list with Back, and the Market's list uses the whole width.
- Beta downloads check your supporter code, and every update is checked against Folio's signing key before it
  installs.

Betas can have more bugs than releases. Settings › Software Update › Beta Updates turns them off, and you stay on
this beta until a newer public release.
```
