# Folio 0.7.0-beta.2 for supporters

The second beta of 0.7.0. Version `0.7.0-beta.2`, versionCode 7000, so it installs cleanly over 0.7.0-beta.1, 0.6.9, and earlier versions, and stable 0.7.0 will install over it. Supporters get it through Market › Sources › Folio Beta.

## What's new since beta 1

- **Island over apps opens its card:** tapping the Dynamic Island on top of another app opens the same card as on Home, with call buttons, media controls and the timer. It closes on swipe up or after 12 seconds, any touch restarts that timer, and Open takes you to the app.
- **Island size:** Settings › Dynamic Island › Advanced island › Size makes the resting island Automatic, Small, Standard or Large. Automatic shrinks it around a small punch-hole camera and leaves notches and the Fold as they were. Standard is how it was.
- **Notification and Quick Settings tiles on Home:** the "Folio Notification Shade" and "Folio Quick Settings" tiles and shortcuts did nothing while Folio's Home was open. Home now shows its own panel.
- **Fold crash fixed:** folding a Fold with Dual-Screen Ambient Light on could close Folio with "ViewTreeLifecycleOwner not found".
- **Icon Actions:** choose what a swipe or a double tap on an icon runs, in Edit Icon and in Settings › Gestures & Actions. An icon's long-press menu lists its actions.
- **Market apps are checked before they install:** the Market makes sure a downloaded app is the one its source listed (same package, at least the listed build, signed by a key the listing names) before Android's install screen. When Install with Folio is missing, the sheet says why.
- **Page effects with more curves:** a page effect package can set curves for more channels, and `folio-pkg` checks them.
- **Control Center Timer and Alarm:** they open the phone's Timer or Alarm screen, or tell you they couldn't.
- **Badges on Dual Messenger copies:** a cloned app has its own badge count, and Clear Badge clears only that copy.
- **Faster Spotlight:** Spotlight, Today View and the Suggestions widget share one ranking of suggested apps, so Spotlight opens with suggestions ready.
- **Shorter What's New and What to Test:** each item is one short line with its own icon.

## What to try, most likely broken first

1. **Island over apps**: play music or start a timer, open another app, tap the island. The card should open, Pause and Play should work, and swipe up or 12 seconds should close it. Try a call too, if you can: Mute, End, Speaker and Open.
2. **Island size**: set each size, then check the island at rest on Home and over an app. On a phone with a small punch hole, try Automatic.
3. **Tiles on Home**: add the Folio Notification Shade and Quick Settings tiles to your pull-down, then tap each while on Home and while in an app.
4. **Fold and unfold** with Dual-Screen Ambient Light on: Folio should stay open.
5. **Icon Actions**: set a swipe action on an icon and run it, then use the long-press menu to run it without the gesture.
6. **Market install**: install an app from a source and check the install goes through. If Install with Folio is missing, tell me what the sheet says.
7. **Control Center Timer and Alarm**: tap each and see that the clock app opens.
8. **Dual Messenger badges**, if you use it: each copy keeps its own count.

Please say which phone, which screen (cover or inner, folded or open) and your Android version with each report. The Korean and Chinese text is machine translated.
