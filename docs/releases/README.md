## Where files go

- **Notes and runbook:** `docs/releases/<version>.md`, written before the build (REL-26 in [the releases standard](../standards/releases.md)).
- **The APK and `SHA256SUMS.txt`:** attached to the GitHub release, never committed. Betas go to `McCal-Codes/folio-beta`, stable releases to `McCal-Codes/folio`.
- **Extra files for one release** (test reports, screenshots, an emulator pass, Lab scene exports): put them in `docs/releases/<version>/` next to the notes and link them from the notes file. Create the folder when you have the first file.
- **Local build copies** (`folio-apks` and the `folio-bN-tag-dist` folders on the build PC) are outside the repository. Note their location in the version's notes file if you want them found later.

## Other files here

`0.7.0-github.md` (GitHub setup for 0.7.0), `kofi.md` and `video.md` are not version notes. `0.15.0-beta01.md` is the old Duo Launcher's release notes, from before the project was named Folio, so it is not a Folio version.
