# Folio 0.6.7.3: Settings search finds tweaks, and two rows line up

Two fixes on top of 0.6.7.2, both found while checking 0.6.7.2 on the Fold8.

## What it fixes

- **Settings search finds tweaks** (#174). Search only indexed pages, so a tweak's name ("flipbook") found nothing.
  Tweaks now match on their name, the tweak they're based on and their one-line description, show "Tweaks" beside
  them, and open their own page (or their Tweak Library page if not added yet).
- **Wallpaper & Appearance lines up again** (#175). The Dark Appearance Dims Wallpaper switch and the note under Also
  Set as Phone Wallpaper sat in groups that don't pad their rows, so both touched the card's edge.

## Version

`folioVersion = "0.6.7.3"`, `versionCode` **6073**. Installs over every 0.6.7. `roadmap.json` doesn't change.
