# Folio 0.6.9.1

**Draft for McCal to rewrite in his own words (REL-25).** A hotfix on 0.6.9, published 10 Nov 2026. Version `0.6.9.1`, versionCode 6091, so it installs over 0.6.9 and anything earlier.

## What's fixed

- **Supporters are told why betas are missing:** Settings > Software Update said "Folio is up to date" when a supporter's check left betas out. It now says which cause it was, with a Supporter button beside it.
- **Spotlight with Reduce Motion:** Spotlight only fades in and out when Reduce Motion is on.
- **App Library while folding:** resetting a search waits for the next layout pass, avoiding a crash when the window changes size.

## Why it is a hotfix

It changes how an update check explains itself on the supporter path. REL-20a allows that as a hotfix only if the same change rides the next beta: it is in 0.7.0 beta 3, as the Beta access card.
