# Folio 0.6.5

The polish release: the layout settings people asked for, a clock worth looking at, updates that install themselves,
and a long list of fixes for folds, tall phones and small windows.

## What's new

Taken from `CHANGELOG.md`, which is what the app shows under Settings › What's New.

- **Clear icons** — frosted glass icons with white symbols.
- **Gauge status glyph** — the battery as an arc with your connection inside it and the percentage above.
- **Big Clock** — a large Lock Screen-style clock with the date and what's next.
- **Layout sliders** — row, column and dock spacing, widget size and status spacing, changing Home as you drag.
- **Apps, dock and status position** — per screen, so a fold can differ from its cover.
- **More rows** on taller screens, the same on both screens of a foldable.
- **Software Update** — updates install themselves overnight, with release notes, Update Now and Update Tonight.
- **Try Folio first** — open Folio as a preview before making it your Home app.
- **Small cover screens** — a focused Home for tiny flip covers.
- **App Library pull-down**, **folder badges**, **better bug reports**, **a live Roadmap**, and the fixes listed in
  the changelog.

## Tested

- The unit suite on the release commit: 366 tests, no failures, run with `--rerun-tasks` so nothing came from cache.
- The support envelope, every sweep green: 17,871 windows from 320×320 to 1600×1200 dp, the same range again with
  large text and layout options, the breakpoint edges, flip/book-fold/tri-fold windows, and micro cover windows.
- The exported geometry table is byte-identical to the one the coverage viewer already carries, so the layout maths
  has not drifted.
- Installed and launched on a Galaxy Z Fold8 (SM-F971U, Android 17): first run and onboarding on the cover screen,
  no crash in the log.

## Known not to work

Worth saying plainly in the notes rather than leaving someone to find it.

- **StandBy only appears when the phone is set down half open.** It is drawn by Folio while Folio is your Home app,
  not by Android, so it cannot come on by itself while the screen is idle — there is nothing to select under
  Settings › Display › Screen saver, and no way to get StandBy on a phone that is simply charging. A supporter asked
  for exactly that on 19 Sep; it is now on the roadmap as *StandBy without the fold*, which needs Folio to register a
  screen saver of its own.
- **A drawing problem reported on the Galaxy Z Fold7**, seen twice and not yet reproduced. Folio has no Fold7-specific
  code: `CameraArea` knows only the Fold8's under-display camera (`SM-F971`) and returns nothing on other models, so
  on a Fold7 nothing is inset for a camera Android doesn't report as a cutout. That is the first thing to rule out —
  it needs one line of data from a Fold7, not a code change (see below).

## Before the release goes out

Only McCal can do the first of these; the rest follow it.

1. **Build and sign** — `scripts/release-signed.sh`, which needs `FOLIO_RELEASE_STORE_FILE`,
   `FOLIO_RELEASE_STORE_PASSWORD`, `FOLIO_RELEASE_KEY_ALIAS` and `FOLIO_RELEASE_KEY_PASSWORD` in the environment. It
   writes `dist/Folio-0.6.5/` with the APK, `SHA256SUMS.txt` and the signing certificate.
2. **Scan the exact APK** on [VirusTotal](https://www.virustotal.com/) and keep the link.
3. **Publish the release** with the APK, its SHA-256 from `SHA256SUMS.txt`, the VirusTotal link, and a line pointing
   at [`PERMISSIONS.md`](../../PERMISSIONS.md) — the three things the release-trust rule asks for.
4. **Then the posts**, in this order: the release post first, the supporter post a day or two later
   (`docs/releases/kofi.md` on the 0.7.0 line has both, and the feature wall is in the Mockup Lab).
5. **Then the four supporter emails**, which say the code switches on when 0.6.5 lands — so they go after it has.

## What to ask the Fold7 reporter

Two answers turn a report nobody can reproduce into a fix:

```bash
adb shell dumpsys window | grep -i udcCutout     # the under-display camera Samsung keeps to itself
adb shell wm size && adb shell wm density        # so the rect can be matched to the panel
```

With those, the Fold7 becomes one more line in `CameraArea.known`. Failing that, 0.6.5's own **Report a Bug** now
copies the diagnostics, which is the no-cable version of the same question.
